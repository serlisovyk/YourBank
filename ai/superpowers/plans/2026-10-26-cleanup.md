# Plan: remove what is unused, tidy the docs (MY-293)

Goal: no unused asset, token or rule stays in the repo, and the `ai/` docs say what the code says
now. No spec: nothing observable changes; the check is a pixel-identical page. Decisions kept:
`fluid-ramps` (single-use values live in their block), `build-pipeline`, `docs` rules in
`ai/rules/docs.md`. The archive `ai/superpowers/` and the text of decision records are not edited.

## Method

Every candidate is grepped across `src/`, `vite/`, `public/`, `.size-limit.json` and the text
files of `public/` before it goes; what cannot be shown dead is reported, not deleted.

## Changes, one commit per kind

- **Assets.** Files of `src/assets/` and `public/` that no HTML, partial, `data/`, CSS, JS, build
  module or `public/` text file names are removed. `public/` files with a fixed URL (`favicon.svg`,
  `og-image.png`, `logo.svg`, `robots.txt`, `sitemap.xml`, `llms.txt`) stay.
- **Tokens.** Custom properties of `variables.css` with no `var(--name)` anywhere go. The type
  tokens used by one block (`--text-title-hero`, `--text-title-md`, `--text-stat`, `--text-value`,
  `--text-card-title-sm`, `--text-plate`, `--text-page-hero-label`) move into that block's
  stylesheet as the same readable ramp, so each value is unchanged.
- **Dead code.** Classes in CSS that no partial or script emits, unused constants, data keys,
  helpers and context keys.
- **Docs.** `ai/map.md`, `ai/rules/`, `ai/skills/`, `ai/design-system.md`, `ai/prompts/`,
  `AGENTS.md` checked against the code: file names, token names, removed facts, decision slugs.
  `ai/design-system.md` goes under its limit by tightening, keeping every value the code relies on.

## Verification

`npm run lint`, `lint:css`, `format:check`, `build`, `size` before and after;
`cmp dist/404.html dist/index.html`. Full-page screenshots of the four pages and the 404 at 1920,
1440 and 390 px (headless Chrome, `prefers-reduced-motion: reduce`, same scrollbar settings),
before and after, pixel-diffed: identical.

## Left out

Anything not provably unused; the archive and the decision records; new tokens or renames.
